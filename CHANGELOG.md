## [0.1.12] — Патч 112: Автоатака по травоядным и браузерный fullscreen

- Автоатака теперь выбирает любую живую особь, включая травоядных (`grazer`), а не только агрессивных или предупреждённых динозавров.
- Мирное поведение травоядных сохранено: они не становятся агрессивными из-за возможности быть атакованными игроком.
- Исправлено определение Telegram Mini App: обычный браузер больше не принимает загруженную Telegram WebApp-заглушку за настоящий Telegram-контекст.
- В обычном браузере кнопка использует Fullscreen API для игрового контейнера; в Telegram остаётся отдельный Telegram Fullscreen API.
- Добавлен обработчик WebKit fullscreenchange для совместимых браузеров.
- Версия обновлена до `0.1.12`, cache-busting ресурсов — до `?v=125`.
